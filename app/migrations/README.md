# DB 추가형 이행

`app/db.py`가 기본 스키마 다음에 파일명 순서로 SQL을 실행합니다.
각 파일은 반복 실행이 가능해야 하며 기존 개인 데이터를 지우지 않습니다.
배포한 SQL은 수정하지 않고 새로운 번호의 파일로 확장합니다.
이전 앱으로 돌아가더라도 추가 테이블을 보존하며 자동 삭제 역이행은 제공하지 않습니다.
`003_learning.sql`은 답안과 독립된 복습 메모·다시 풀기 표시를 저장합니다.
계약은 [데이터 모델](../../docs/data-model.md), 검사는 [검증 안내](../../docs/testing.md)를 따릅니다.

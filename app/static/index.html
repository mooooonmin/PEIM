보완 메모와 다시 풀기는 ‘복습 저장’을 눌러야 DB에 저장됩니다.

저장 문제 해결

연결 기출

주제를 선택하면 연결된 기출문항을 볼 수 있습니다.

전체 다시 풀기

주제·회차에 관계없이 다시 풀기로 저장한 문항과 보완 메모를 모았습니다.

이어서 풀기는 기존 답안을 그대로 엽니다. 복습 후 표시를 해제하려면 복습 단계에서 ‘다시 풀기’를 끄고 저장하세요.

문제 관리

기존 문항을 검수하거나 PDF에서 새 문항을 등록합니다.

  1. PDF 등록 또는 기존 시험지 선택
  2. 문항 추출 또는 직접 입력
  3. 원본 대조 후 문항 등록

PDF 첨부

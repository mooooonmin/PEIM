# 학습 콘텐츠 원본

답안·주제·키워드·도식의 원본과 수정본을 보존합니다. 사용자 답안 저장소가 아닙니다.

| 경로 | 역할 |
| --- | --- |
| `answers/` | 주제별 참고 답안 원본 |
| `topics/` | 주제 분류 자료 |
| `manual/` | 수기 전사 자료 |
| `rules/` | 수정·병합·키워드 규칙 |
| `work/` | 기존 수정본과 키워드·도식 작업 자료 |
| `overrides/` | 근거를 남긴 최종 덮어쓰기 데이터 |

[보존·적용 순서](../docs/content-pipeline.md)를 따릅니다. 기존 GUIDE의 이전 경로는 역사적 기록입니다.
변경 후 [데이터 검사](../docs/testing.md#데이터-검사와-내보내기)를 수행합니다.
`work/kwviz/out`도 보존 대상 원본이며 일반 임시 출력으로 취급하지 않습니다.

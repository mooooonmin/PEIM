# 데이터 기준 목록

원본 보존과 안정적인 식별자를 검사하는 기준 파일입니다.

| 경로 | 역할 |
| --- | --- |
| `catalog.json` | 버전 관리된 회차와 원본 첨부 목록 |
| `preservation.json` | 보존 대상 경로·기준 커밋·해시 |
| `stable_ids.json` | 기존 식별자 기준 |

[데이터 계약](../docs/data-model.md)과 [갱신 절차](../docs/content-pipeline.md#새-자료-반영)를 따릅니다.
변경 후 [데이터 검사](../docs/testing.md#데이터-검사와-내보내기)를 수행합니다.
검사를 통과시키려는 목적으로 변경 이유 없이 기준 해시를 갱신하지 않습니다.

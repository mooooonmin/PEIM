# 로컬 앱 구현 검증 기록

2026-11-19, `codex/local-study-app` 작업의 로컬 검증입니다. 독립 리뷰가 아닌 자체 검토입니다.

- `python -m unittest discover -s tests -v`: 19개 중 데이터 14개와 백업 4개 통과,
  앱 모듈 1개는 호스트 실행 보호 조건으로 건너뜀.
- `docker compose --profile test run --build --rm test`: 별도 PostgreSQL의 앱 검사 11개 통과.
  답안 충돌/동시 저장, 이력/재초기화 보존, 업로드 중복/충돌/동시성/크기/형식,
  파일만 남은 상태의 재등록, 추출/수동 등록, 로컬 요청 제한 포함.
- `python scripts/validate_data.py`: ID·연결·답안 범위·원본 해시·보존 검사 통과.
- `python scripts/check_rebuild.py`: 모든 공개 데이터 파일이 재생성 결과와 바이트 단위로 일치.
- `npm run build`, `docker compose config --quiet`, `git diff --check`: 통과.
- `npm audit --omit=dev`: 실행 시 보고된 취약점 없음. 취약점이 영구히 없다는 보장은 아님.
- `docker compose up -d --build --wait web`: 웹과 DB healthy 확인.

## 브라우저

실제 원본 폴더 대신 복사한 139회 PDF와 테스트용 빈 PDF를 사용하는 별도 Compose 프로젝트에서 확인했습니다.

- 답안 자동 저장 후 다른 문항으로 이동·복귀 및 페이지 재진입: 글과 저장 상태 유지.
- 주제 참고 답안의 Markdown 표와 Mermaid SVG 표시, 확인 시 브라우저 오류 로그 없음.
- 140회 테스트 PDF 등록: `제140회_정보관리기술사.pdf`로 저장.
- 빈 PDF 추출 후 수동 입력 안내, 원문 확인 표시·페이지·주제 연결 후 문항 등록 및 회차 탐색 반영.
- 실제 139회 PDF 추출: 문항 후보 표시. 후보 전체의 내용 정확성은 검증하지 않음.
- 집중 모드 전환, 데스크톱 3열 및 390px 모바일 화면 확인. 모바일 문서의 가로 넘침 없음.
- 최종 기본 프로젝트 화면 표시 확인. 테스트 글과 140회 시험지는 기본 프로젝트에 넣지 않음.

## 백업 복원

별도 `peim-qa` 프로젝트를 백업한 뒤 새 `peim-restore` DB와 별도 폴더로 복원했습니다.
`verify` 해시 검사, 복원된 답안 내용 일치, 두 PDF 원본 바이트 일치를 확인했습니다.
검증 후 QA/복원 서비스는 종료했고 기본 프로젝트는 실행 상태로 두었습니다.

## 범위와 제한

- 로컬 로그인 없는 개인용 앱. 다중 사용자 인증과 원격 공개 운영은 미구현.
- 이미지 PDF OCR, HWP 추출, 원본 교체, 이미 등록한 문항 편집은 미구현.
- 전체 자료의 학술적 정답 검증은 수행하지 않음. 참고 답안은 주제 학습 자료로 표시.
- Python TestClient에서 httpx 사용의 향후 중단 경고가 발생하지만 검사 실패는 없었음.
- GitHub 검사와 병합 기록은 해당 PR에서 확인합니다.

# 참고 답안·작성 예시 형식 정리

## 목표와 설계

학원 해설은 구성 참고로만 사용한다. 주제 해설은 제목 단계·문단을 통일하고,
문항 가이드는 비교·계산·절차·설계·개념 요구에 맞춰 구성한다. 기존 자료와 개인 답안은 보존한다.
원본 일괄 재작성 대신 조회 시 표시 형식을 정리하고, 원문 해시가 일치할 때만 출처가 있는 교정본을 적용한다.
이 방식은 기존 DB에서도 재가져오기 없이 적용되며 다른 버전의 자료를 덮어쓰지 않는다.

## 실행 순서

- [x] `app/answer_format.py`와 교정 자료: 코드 블록·표·링크 보존, 반복 적용 안정성, 원문 불일치 검사.
- [x] `app/writing_guide.py`, 작성 예시: 유형별 목차·힌트, 문항 원문 일치와 수치 검증.
- [x] API와 화면: 읽기 전용 교정본과 근거 제공, 키워드 표현 정리, 기존 답안·메모·이력 보존 검사.
- [x] 문서 갱신과 로컬·Docker·브라우저 검사. 원격 CI·병합 상태는 해당 PR에서 관리.

## 완료 조건과 제한

검사 명령은 [개발 검사](../../testing.md)를 따른다. 전체 자료의 형식 검사와
일부 내용 교정을 구분한다. 전 답안의 학술적 검수 완료로 표시하지 않는다.
사용자 자료·콘텐츠 원본·시험지와 식별자를 수정하지 않는다.

## 현재 상태

구현·로컬 검증 완료. 별도 코드 리뷰에서 산출물의 계산형 오분류를 발견하여 실제 문항 회귀 검사로 수정했다.
검증 결과와 원격 반영 상태는 해당 변경의 커밋·PR에 기록한다.
